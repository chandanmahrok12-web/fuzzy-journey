PLAIN-LANGUAGE NOTICE

A quieter kind of web.

This website is designed to work without an account. This notice describes the behavior of the current static-site implementation and should be reviewed when services or analytics are added.

Information you provide

The current site does not provide an account-registration form or ask you to submit personal profile information. Avoid sending sensitive information through external channels linked from this website.

Local browser storage

The Reality Kit can remember which prompts you marked as completed by using local storage in your browser. That list stays in the browser on your device; it is not sent to a UNPLUG LABS server by the current implementation. You can reset the list using the reset control or clear this site's local storage in your browser settings.

Analytics and advertising

The current source code does not add analytics or advertising scripts by default. If analytics, embedded services, or external media are added later, this notice should be updated to explain what they collect and link to relevant provider policies where appropriate.

External links

Links to other sites follow the destination site's own privacy practices. Review those policies before sharing information with an external service.

Updates

This notice describes the current website implementation, not a substitute for legal advice. Review it when the site's functionality, hosting, or data practices change.
